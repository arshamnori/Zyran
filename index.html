از مبتدی تا حرفه‌ای در ۶ مرحله

اگه نمی‌دونی از کجا شروع کنی، این مسیر رو قدم‌به‌قدم دنبال کن.

مرحله ۱ — تفکر الگوریتمی

یاد می‌گیری مثل یک برنامه‌نویس فکر کنی: متغیر، شرط، حلقه، تابع.

مرحله ۲ — HTML و CSS

ساختار و ظاهر وب‌سایت رو می‌سازی؛ تگ‌ها، استایل، فونت، ریسپانسیو.

مرحله ۳ — بوت‌استرپ ۵

با بوت‌استرپ در چند دقیقه سایت‌های زیبا و ریسپانسیو می‌سازی. گرید، کامپوننت‌ها، RTL و یوتیلیتی‌ها.

مرحله ۴ — جاوااسکریپت

به صفحه‌ات جان می‌دی؛ DOM، ایونت‌ها، آرایه‌ها، Promise و async/await.

مرحله ۵ — یک فریم‌ورک (React)

ساخت اپلیکیشن‌های واقعی با کامپوننت‌ها، state و روتر.

مرحله ۶ — بک‌اند و دیپلوی

سرور، دیتابیس، احراز هویت، API و دیپلوی روی گیت‌هاب و سرویس‌های میزبانی.

شش مرحله‌ی بالا مسیر پیشنهادی است؛ هر کدوم رو که تموم کردی، روی آن مرحله تیک بزن.

const toggle = document.getElementById('themeToggle');
toggle.addEventListener('click', () => {
  const html = document.documentElement;
  const cur = html.getAttribute('data-bs-theme');
  const next = cur === 'dark' ? 'light' : 'dark';
  html.setAttribute('data-bs-theme', next);
  localStorage.setItem('theme', next);
});

function copyCode(btn) {
  const code = btn.parentElement.innerText.replace('کپی','');
  navigator.clipboard.writeText(code);
  btn.textContent = 'کپی شد ✓';
  setTimeout(() => btn.textContent = 'کپی', 1500);
}

سؤالات متداول

چیزایی که زیاد پرسیده می‌شه

بهترین نقطه شروع، یادگیری تفکر الگوریتمی با یک زبان ساده مثل پایتون است. بعدش HTML/CSS و بعد بوت‌استرپ و جاوااسکریپت. نقشه‌راه بالای همین سایت همین مسیر رو بهت نشون می‌ده.

بوت‌استرپ (Bootstrap) محبوب‌ترین فریم‌ورک CSS دنیاست که با کلاس‌های آماده، سایت‌های زیبا و ریسپانسیو رو خیلی سریع می‌سازی. همین سایت خودمون با بوت‌استرپ ۵.۳.۳ نسخه‌ی RTL (راست‌چین) ساخته شده و به‌صورت لوکال (دانلود شده در هاست) لود می‌شه — پس هیچ لینک شکسته یا وابستگی CDN نداره.

بله! تمام درس‌ها، کدهای آماده و آزمون‌های زیرن کاملاً رایگان هستند. هدف ما ترویج برنامه‌نویسی بین فارسی‌زبان‌هاست.

فقط یک مرورگر (مثل کروم یا فایرفاکس) و یک ویرایشگر کد مثل VS Code. برای پایتون هم نصب Python 3 از سایت رسمی کافیه.

نکته، پیوستگی‌ست نه ساعت زیاد. روزی ۳۰ تا ۶۰ دقیقه تمرین پیوسته، خیلی بهتر از ۸ ساعت یک روز در هفته است.

در نسخه‌ی فعلی سایت، همه چیز روی مرورگر تو (localStorage) ذخیره می‌شه. در نسخه‌های آینده سیستم حساب کاربری و ابری اضافه می‌شه.
