# زیرن Zyran — سایت آموزش برنامه‌نویسی

سایت آموزش برنامه‌نویسی فارسی. صفحه‌ی اصلی `index.html` یک فایل کامل و مستقل است (CSS و JS داخل خود فایل‌اند).

## امکانات
- دوره‌های آموزشی با جستجو و فیلتر دسته‌بندی
- نقشه‌راه یادگیری در ۶ مرحله
- نمونه‌کدهای قابل کپی (HTML، Bootstrap، CSS، JavaScript، Python)
- آزمون تعاملی ۵ سؤالی
- ابزارها: شمارنده متن، تولیدکننده رنگ HEX، تولیدکننده رمز عبور
- سؤالات متداول، خبرنامه، تم روشن/تاریک (ذخیره در مرورگر)

## ساختار
```
index.html                  # کل سایت (HTML + CSS + JS)
vendor/bootstrap/           # Bootstrap 5.3.3 RTL (لوکال، از npm)
vendor/fonts/               # فونت Vazirmatn (لوکال)
CNAME, robots.txt, sitemap.xml
_old_site/                  # صفحات قدیمی سرور ماینکرفت (آرشیو)
```

## اجرا
فایل `index.html` را در مرورگر باز کنید؛ نیازی به سرور یا اینترنت نیست.
